# MT5 Fast Close & Dual-Mode Trader（MT5 快速平仓 + 双模式交易工具）

> **核心作用**：持仓单多的时候，MT5 里 EA 自己逐单平仓非常慢。本工具直接调用 MT5 终端自带的**「一键全平」**——先定位 MT5 窗口，右键弹出终端菜单，用上下键遍历到"全部平仓"再回车执行，**几十上百单也能一次清掉**。
> 其余（ADX/RSI 双模式自动开仓、后台服务、GUI 监控）只是辅助功能，交易策略本身 MT5 的 EA 本来就能实现。

## 为什么需要它

| 场景 | MT5 / EA 原生做法 | 本工具 |
|---|---|---|
| 持仓 1~几十单 | EA 逐单发平仓请求，慢但能用 | 走 MT5 API 逐单平（同样路径，更省心） |
| **持仓几十~上百单** | EA 逐单循环，越平越慢，行情跑掉 | 直接调终端「一键全平」，一次清空 |

工具会自动判断：`close_all_smart()` 读取当前持仓数，**小于 50 单**走 API 逐单平，**达到 50 单**改用 GUI 一键全平（阈值见 `CLOSE_THRESHOLD`）。

## 快速平仓是怎么做的

```
定位 MT5 窗口（按标题 / 账号过滤，支持多开）
        │
        ▼
Win32 激活窗口到前台
        │
        ▼
终端区域右键（窗口下方 75% 高度处）
        │
        ▼
↓ ↓ ↓ ↓   （上下键遍历到「全部平仓」菜单项）
        │
        ▼
→ 展开子菜单 → Enter → Enter
        │
        ▼
MT5 终端执行一键全平
```

> **实现演进**：早期版本用**屏幕图像识别**（匹配按钮截图）定位菜单，换个分辨率或主题就失效；
> 现行版本改为**窗口句柄定位 + 键盘上下键遍历**，不依赖任何截图素材，稳定性大幅提升。
> 操作结束后会把焦点还给原来的窗口，不打断你正在做的事。

## 架构

```
┌──────────────┐   JSON over TCP (localhost:19527)   ┌──────────────────┐
│  gui_dual.py │ ←----------------------------------→ │    service.py    │
│  tkinter GUI │                                      │   后台交易服务    │
└──────────────┘                                      └────────┬─────────┘
                                                               │
                                                      ┌────────▼─────────┐
                                                      │  trader_dual.py  │
                                                      │ 策略 + 快速平仓   │
                                                      └────────┬─────────┘
                                                     ┌─────────┴─────────┐
                                                     ▼                   ▼
                                             MT5 Python API        窗口 / 键盘自动化
                                          （逐单平、下单、取数）    （一键全平，走终端）
```

- **service.py**：独立后台进程，不依赖 GUI / 桌面会话（断开远程桌面后交易继续运行）
- **gui_dual.py**：参数配置、启停控制、实时状态与日志、应急一键清仓
- **trader_dual.py**：ADX/RSI 双模式策略 + 智能平仓调度

## 辅助：ADX 双模式开仓逻辑

| 行情状态 | 判定 | 入场逻辑 |
|---|---|---|
| 趋势 | ADX ≥ 25 | 顺势：价格站上均线且 RSI 未极端时顺方向开单 |
| 震荡 | ADX < 20 | 逆势：价格偏离均线 ≥ 阈值且 RSI 到超买/超卖时反向开单 |
| 过渡区 | 20 ≤ ADX < 25 | 静默，不开新单 |

这部分与 MT5 EA 的能力重叠，只是顺手集成进来，不是本项目的重点。

## 使用方法

1. Windows + 已登录的 MetaTrader 5 终端（算法交易按钮开启）
2. 安装依赖：

   ```
   pip install MetaTrader5 pyautogui pygetwindow
   ```

3. 启动后台服务：`python service.py`
4. 启动 GUI：`python gui_dual.py`，填参数后点「启动」
5. 需要清仓时点「全部平仓」，或让策略按止盈 / 止损自动触发

打包单文件 exe 可用 `scripts/` 下的 PyInstaller spec：

```
pyinstaller scripts/MT5自动交易.spec
```

## 配置说明（config.json，GUI 可视化修改）

| 键 | 说明 | 默认 |
|---|---|---|
| MT5_ACCOUNT_FILTER | 目标 MT5 账号，0 = 使用当前已登录账号 | 0 |
| SYMBOL | 交易品种（不同经纪商后缀可能不同，如 XAUUSDm） | XAUUSDm |
| TIMEFRAME | K 线周期 M1~D1 | M5 |
| STRATEGY_MODE | 手动模式下的固定策略：shunshi（顺势）/ nishi（逆势）；AUTO_MODE=true 时由 ADX 自动切换，此键不生效 | shunshi |
| ADX_RANGE_MAX / ADX_TREND_MIN | 模式切换阈值 | 20 / 25 |
| LOT_SIZE | 每单手数 | 0.01 |
| TAKE_PROFIT_USD / STOP_LOSS_USD | 单笔止盈/止损（美元） | 30 / 5000 |

完整示例见 [config.example.json](config.example.json)。
